
# Requisitos del Sistema

- **RF-01:** El usuario debe poder registrarse e iniciar sesión con su correo y contraseña.
- **RF-02:** El paciente debe poder visualizar el catálogo de médicos y sus especialidades.
- **RF-03:** El paciente debe poder seleccionar fecha y hora para agendar una cita médica.
- **RF-04:** El sistema debe enviar un correo de confirmación al agendar una cita.
- **RF-05:** El administrador debe poder cancelar o reprogramar citas médicas.
- **RF-06:** El paciente debe poder recibir recordatorios vía SMS 24 horas antes de su cita.
